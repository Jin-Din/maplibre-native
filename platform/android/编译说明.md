

## 基础包
- MapLibre Native 13.0.2
## 编译环境
- Android Studio Panda 4 | 2025.3.4 Patch 1
- Gradle 9.3.1

## 编译步骤
## 1. 更新子模块
```
cd 到工程根目录
git submodule update --init --recursive
```

## 问题

## 1.   License not found for target: mbgl-vendor-eternal 或者 mbgl-vendor-boost

- 从 [mapbox/eternal](https://github.com/mapbox/eternal/tree/8eee3476198f99c2e2621b36f764a5a30bd71ab7) 手动下载zip，解压到工程根目录下的 vendor\eternal
- 从 [maplibre-gl-native-boost](https://github.com/maplibre/maplibre-gl-native-boost) 手动下载zip,解压到工程根目录下的 vendor\boost
