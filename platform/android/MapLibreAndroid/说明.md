# Android平台引用mbgl底层代码库的架构分析

## 整体架构概览

MapLibre Native采用**分层架构**设计，Android平台通过**JNI桥接层**和**CMake构建系统**引用底层C++库：

```
┌─────────────────────────────────────────────────────────────────┐
│                    Android SDK (Java/Kotlin)                   │
│  platform/android/MapLibreAndroid/src/main/java                │
├─────────────────────────────────────────────────────────────────┤
│                      JNI 桥接层 (C++)                          │
│  platform/android/MapLibreAndroid/src/cpp/                     │
│  └── maplibre.so (共享库)                                      │
├─────────────────────────────────────────────────────────────────┤
│                      mbgl-core (静态库)                        │
│  src/mbgl/ (核心C++引擎)                                       │
│  platform/android/src/ (Android平台适配)                       │
│  platform/default/src/ (默认平台适配)                          │
└─────────────────────────────────────────────────────────────────┘
```

---

## 1. CMake构建系统的引用机制

### 1.1 Android模块的CMakeLists.txt

**文件**: `platform/android/MapLibreAndroid/src/cpp/CMakeLists.txt`

```cmake
# 关键步骤1: 通过add_subdirectory引入根目录的CMake配置
add_subdirectory(../../../../../ ../../../../../${ANDROID_ABI})

# 关键步骤2: 定义Android平台的共享库
add_library(maplibre SHARED
    main.cpp
    jni_native.cpp
    android_renderer_backend.cpp
    # ... 大量JNI封装文件
)

# 关键步骤3: 链接到mbgl-core静态库
target_link_libraries(maplibre
    PRIVATE
        mbgl-core                    # 核心C++库
        mbgl-vendor-unique_resource  # 第三方依赖
)

# 关键步骤4: 设置头文件路径
target_include_directories(maplibre
    PRIVATE
        ${PROJECT_SOURCE_DIR}        # JNI层头文件
        ../../../../../src           # mbgl核心头文件
        ../../../src                 # 平台相关头文件
        ../../../../default/include  # 默认平台头文件
)
```

### 1.2 根目录CMakeLists.txt中的mbgl-core定义

**文件**: `CMakeLists.txt`

```cmake
# 定义核心静态库
add_library(mbgl-core STATIC)

# 添加核心源代码
list(APPEND SRC_FILES
    ${PROJECT_SOURCE_DIR}/src/mbgl/gfx/drawable.cpp
    ${PROJECT_SOURCE_DIR}/src/mbgl/renderer/renderer.cpp
    ${PROJECT_SOURCE_DIR}/src/mbgl/map/map.cpp
    # ... 大量核心模块
)

# 将源文件添加到mbgl-core
target_sources(mbgl-core PRIVATE ${SRC_FILES})
```

### 1.3 Android平台特定配置

**文件**: `platform/android/android.cmake`

```cmake
# 为mbgl-core添加Android平台特定的源代码
target_sources(mbgl-core
    PRIVATE
        ${PROJECT_SOURCE_DIR}/platform/android/src/async_task.cpp
        ${PROJECT_SOURCE_DIR}/platform/android/src/attach_env.cpp
        ${PROJECT_SOURCE_DIR}/platform/android/src/bitmap.cpp
        ${PROJECT_SOURCE_DIR}/platform/android/src/jni.cpp
        ${PROJECT_SOURCE_DIR}/platform/android/src/run_loop.cpp
        # ... Android平台适配代码
)

# 添加默认平台的源代码
target_sources(mbgl-core
    PRIVATE
        ${PROJECT_SOURCE_DIR}/platform/default/src/mbgl/storage/asset_file_source.cpp
        ${PROJECT_SOURCE_DIR}/platform/default/src/mbgl/storage/database_file_source.cpp
        ${PROJECT_SOURCE_DIR}/platform/default/src/mbgl/map/map_snapshotter.cpp
        # ... 默认平台实现
)

# 链接Android系统库
target_link_libraries(mbgl-core
    PRIVATE
        EGL           # OpenGL ES支持
        GLESv3        # OpenGL ES 3.0
        android       # Android原生API
        atomic        # 原子操作支持
        jnigraphics   # JNI图形支持
        log           # 日志库
        mbgl-vendor-icu    # ICU国际化库
        mbgl-vendor-sqlite # SQLite数据库
        z             # zlib压缩
)
```

## 2. Gradle构建配置

### 2.1 Android模块配置

**文件**: `platform/android/MapLibreAndroid/build.gradle.kts`

```kotlin
android {
    // 配置NDK版本
    ndkVersion = Versions.ndkVersion

    // 产品变种 - 支持多种渲染后端
    productFlavors {
        create("opengl") {
            externalNativeBuild {
                cmake {
                    arguments("-DMLN_WITH_OPENGL=ON")
                }
            }
        }
        create("vulkan") {
            externalNativeBuild {
                cmake {
                    arguments("-DMLN_WITH_VULKAN=ON")
                }
            }
        }
        create("webgpuDawn") {
            externalNativeBuild {
                cmake {
                    arguments("-DMLN_WITH_WEBGPU=ON", "-DMLN_WEBGPU_IMPL_DAWN=ON")
                }
            }
        }
    }

    // 构建本地库
    val nativeTargets = mutableListOf("maplibre")
    nativeBuild(nativeTargets)
}
```

## 3. 引用关系总结

| 层次 | 库名称 | 类型 | 位置 | 职责 |
|------|--------|------|------|------|
| **核心层** | mbgl-core | 静态库 | `src/mbgl/` | 地图渲染核心引擎 |
| **平台适配层** | - | 源码 | `platform/android/src/` | Android平台特定实现 |
| **JNI桥接层** | maplibre | 共享库 | `platform/android/MapLibreAndroid/src/cpp/` | Java与C++交互 |
| **Android SDK层** | MapLibreAndroid | Android库 | `platform/android/MapLibreAndroid/src/main/java/` | Java API封装 |

---

## 4. 构建流程

1. **Gradle触发**: Android Studio或命令行执行构建
2. **NDK构建**: Gradle调用CMake执行nativeBuild
3. **CMake配置**:
    - 首先执行根目录CMakeLists.txt，构建mbgl-core静态库
    - 然后执行android.cmake，添加Android平台代码
    - 最后执行Android模块的CMakeLists.txt，构建maplibre共享库
4. **链接阶段**: maplibre.so链接mbgl-core及依赖库
5. **产物**: 生成`libmaplibre.so`供Java层调用

## 5. 关键技术要点

### 5.1 渲染后端的条件编译

通过CMake选项控制渲染后端：

```cmake
if(MLN_WITH_OPENGL)
    target_sources(mbgl-core PRIVATE ...)
endif()

if(MLN_WITH_VULKAN)
    target_sources(mbgl-core PRIVATE ...)
endif()

if(MLN_WITH_WEBGPU)
    target_sources(mbgl-core PRIVATE ...)
endif()
```

### 5.2 JNI交互机制

Android层通过JNI调用C++核心功能：

- **Java层**: `org.maplibre.android.*` 包中的类
- **JNI层**: `jni_native.cpp` 等文件实现JNI接口
- **核心层**: 调用mbgl-core提供的C++ API

### 5.3 平台抽象设计

mbgl-core通过**抽象接口**实现平台无关性：

- `platform/android/src/`: Android特定实现
- `platform/default/src/`: 通用平台实现
- `platform/linux/src/`: Linux特定实现（供Android OpenGL使用）

这种设计使得核心引擎代码无需修改即可跨平台复用。
